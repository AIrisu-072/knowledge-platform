## Execution and acceptance procedure

1. Admit one model/runtime at a time only after a fresh free disk/memory check and full peak calculation. Fetch only listed files at the exact revision; stream SHA-256 and byte-count verification. Keep downloads temporary until verified; remove only owned `.partial` files after a failed attempt. Native tar extraction must reject path traversal, symlinks escaping the owned root and unexpected file/architecture. No implicit network fetch by tokenizer, Candle, `ort`, Cargo build or runtime. A later actual model worker separately proves offline load/query/rebuild with outbound access blocked.
2. Capture query/Unit text, normalized P1 codec, Source generation, current Read, filter, 20-candidate window, 32/256/1024 scale, actual S1 planner order and all local code/build/asset digests in `pre_run_inputs`. Freeze and persist the same-code `RunPin` **before** replaying L/LG. The planned LDG sequence is Lexical → Vector → HyperGraph; verify actual planner output and preserve Lexical before HyperGraph. Hard eligibility precedes S1. Fold multiple Unit hits to one parent Version `ResourceId` before rank reporting; retain distinct Part/raw/locator in trace. Raw scores never cross retriever arithmetic. No Vector score, hit or ANN miss proves `BodyRequired`, exact body text, absence or current `Read`.
3. Numerical oracle is test-only. For fixed Japanese/mixed, padded, 127/128/512-boundary, prefix and long inputs, require exact token IDs/special tokens/masks/truncation, 384 finite nonzero values, L2 retrieval norm in `[0.9999, 1.0001]`, maximum component absolute error `0.002`, and maximum cosine absolute error `0.0001` versus a pinned reference. Any reference pair with cosine margin `>0.0002` must keep its order in Rust. Smaller-margin reversals are listed per query; a judged top-k change requires review. Compare native raw pool and retrieval-normalized vectors separately. Compare Candle and `ort` on at least one identical real model, run sequentially so both runtimes are not resident together, and record actual load/query RSS and time. A reference-only PASS is not Rust parity.
4. Measure real exact D/LD/LDG alongside real L/LG on the same pinned corpus, labels, Source eligibility, window and host. Parent `Recall@1/5/10/20` denominator is all eligible positives in the closed corpus; report `MRR@10`, `nDCG@10` with `2^grade−1` gain, Unit/logical parent recall, Graph-only rescue, false composites, unjudged fraction and each security miss. No-positive relevance ratios are undefined; visible false positives and unauthorized disclosure are separate counts. Report every small fixture case, then query-bootstrap intervals only when sample size supports them. Public qrels have only binary grades; never invent grade 2/3.
5. Record cold/warm model load, embed, scan, Source resolver/Read, fusion, disclosure, build, update, purge and restart timings; process RSS sampled and peak, model residency, index/cache/disk and host contention. `p99` from fewer than 100 independent timed requests is only a descriptive maximum. ANN gets a separate same-vector/same-filter exact oracle, plus add/change/delete, lease purge, restart and filtered underfill. Neither a fake rank list nor an ANN specification establishes measured quality. Freeze decision thresholds and priority query strata **before** opening the public holdout; a tie, wide uncertainty or material critical-stratum regression leaves Vector default `Disabled`.
