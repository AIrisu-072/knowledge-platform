# 文書検索ツールの使い方（手引き）

## ツールの性質
- search_keyword: 本文の語の一致で探す。日本語は2文字ずつに区切って照合するため、短く特徴的な名詞（例:「公認会計士 登録」）が強い。長い自然文は語の6割以上が一致した箇所を拾う。固有名詞・条番号・型番・年号の検索に向く。
- search_semantic: 意味の近さで探す。言い換え、説明的な質問（「〜するための〜」）、名前が分からない対象に向く。似ているだけの文書も返るので、本文の確認が必須。
- read_document: id と query を渡すと、本文中で query の語に近い行を前後つきで返す。query を省くと page 単位で先頭から読む。法令など長い文書は query を条番号や用語で絞る。
- note: 途中の発見を記録する。長い調査で前の結果を忘れないために使う。

## 結果の見方
- 結果の seen: true は既に見た文書。
- 古い検索結果は履歴から省略される。必要な id とタイトルは note に残す。
- 同じ法令に版が複数ある場合はタイトルが同じになる。本文で施行日などを確かめる。

## 終え方
- 根拠の文は本文からそのまま引用する（要約しない）。
- 「該当なし」も正しい回答になりうる。根拠が無いのに似た文書を挙げると誤り。
