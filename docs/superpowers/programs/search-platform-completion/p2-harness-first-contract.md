# P2 Harness-first PoC contract

- Scope: isolated credential-free evaluation code, not production Vector selection or full P1 body qualification. Parent fixes the stable harness contract reported by P2 design worker; final P2 architecture reconciles it. Frozen Unit input is `p1-knowledgeunit-freeze.md`.
- Files: `experiments/search-vector-poc/{Cargo.toml,Cargo.lock,README.md,corpus_manifest.json,queries.jsonl,qrels.jsonl,src/{lib,validate,corpus,run,metrics,report}.rs,tests/{frozen_unit_codec,relevance,security}.rs}`. Isolated `[workspace]`; root Cargo untouched. Reuse the existing qualified Tantivy dependency patch and exact workspace versions explicitly where an isolated root must declare them. No model/runtime dependency or weight in this first slice.
- `validate_corpus()` verifies exact frozen Version/Part/Unit/locator/profile/raw/text bindings and UnitId golden vectors. Corpus is synthetic Japanese/mixed text with explicit deterministic seed, multiple eligible parent Resources, graph-only relevance, related-but-not-eligible distractors, denied/unknown-current-access and mismatched-generation cases. No customer/private/NoRetention provider data.
- `run_arm(arm, pinned, actor, window)` initially runs **actual existing** Lexical and Lexical+Graph implementations, not a lexical score or fake adjacency substitute. Core generation/current Read/temporal/hard eligibility and S1 PriorityConcat apply equally. Dense arms are explicitly unrun until real model adapter arrives; do not publish zero or fabricated dense scores. Unit/Resource folding preserves parent identity and eligible qrels.
- Corpus record schema and qrels keep SourceId, pinned generation, Version/Part/Unit ID, locator/profile/text digest, current visibility, parent Resource ID and relevance grade (0..=3) separate. Multiple positive eligible parents and graph-only qrels are mandatory. Ineligible records never enter evaluation output.
- `score_run()` reports Recall@1/5/10/20, MRR@10 and nDCG@10 on deduplicated parent Resource ranks. Recall denominator is all eligible positive parent qrels. Reciprocal rank uses the first eligible positive. DCG gain is 2^grade−1 with log2(rank+1) discount, IDCG sorts eligible gold grades. No-positive queries are reported separately with undefined relevance ratios, never silently perfect. Preserve raw retriever ranks/stage misses; raw scores never added.
- `measure_run()` reports measured query/build/update/fusion timings, p50/p95/p99, process RSS and index disk bytes with method and sample count. Run scales sequentially (initial 32/256/1024 Resources, bounded text sizes); record cold/warm distinction and host contention. RSS is real process measurement, not a theoretical model estimate. No proposed SLO at this stage.
- Tests assert golden codecs, correct metric fixtures independent of retriever code, multi-positive qrels and graph-only return, denied/unknown/pin mismatch exclusion, strict S1 order. Mock Vector port may only test contract failures (dimension/NaN/stale binding/retention); it is not model-quality evidence.
- Root disk observation is 4.9 GiB free and falling from other activity; debug=0/incremental=0/jobs=2, no multiGB download. Preserve report/receipts, clean only owned disposable PoC output when no longer needed. First slice reports baseline evidence in `report.md` with exact commands and fixture seed. Models and production engine selection are later independent measured tasks.
