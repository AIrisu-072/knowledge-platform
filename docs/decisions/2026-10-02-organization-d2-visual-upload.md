## Content and storage boundary

The server reads an immutable snapshot of the eight reviewed source inputs and
serves only six exact runtime basenames. It never serves the repository root,
unit tests, directories, private files, logs or credentials. It rejects symlink
ancestry, symlink/nonregular/hardlinked/oversized source inputs, traversal,
encoded paths, hostile Host headers and non-GET/HEAD methods. Strict CSP,
context routing, blocked service workers and WebSockets, no downloads, and a
small browser environment bound the source page's network surface. This is
browser-context request proof, not a claim of an operating-system firewall for
Chromium background traffic or the Actions installer/uploader.

Both pages' ten named scenario controls must select their defined modules.
All non-capture assertions finish before any screenshot. Every capture uses a
fresh context/page at1440×900 and full-page CSS pixels bounded to900–2400px high;
no1280 screenshots are exported. Captures preserve focus and repeat state,
geometry and actual font checks. Only the20 literal `sales-<state>.png` /
`office-<state>.png` names may enter export. They are owned private single-link
regular files, no symlinks or executables, at most8MiB each. Strict PNG validation
allows only pixel IHDR/IDAT/IEND chunks, CRC-checked bounded truecolor decoded
pixels, fixed width and bounded height; metadata/trailing data is rejected.

The atomic export is created only after all assertions, browser/server cleanup,
unchanged clean source/head and the live review recheck. No videos, traces,
reports, logs, transcript files, manifests, credentials or extra image files are
uploaded. The uploader uses20 literal paths, `retention-days: 1`, no overwrite,
no hidden files, safe head/run-bound artifact name and success-only output gate.
Raw browser/assertion failures are reduced to fixed categories; the bounded
console receipt contains safe basenames, source blob/SHA256 identities, head,
tree and run subjects, never source bodies, private paths or CDP payloads.

Repository administration/Actions allowlist settings remain unknown. A policy
or hosting rejection must be reported; no bypass, custom uploader or new store
is authorized. Inspect actual artifact count, dimensions, contents, digest,
