# 正式改訂の単体詳細と過去公開版の取下げ

## 正式改訂の詳細

文書詳細の「版・改訂」を開き、正式改訂一覧の「改訂 n.m の詳細」を押します。選択した改訂の確定日時、種類、内容版ID、保存時のメタデータ、実行者、理由を表示します。改訂番号は文書の更新競合用revisionやコンテンツ版番号とは別です。メタデータの履歴snapshotがない旧データは「過去のメタデータは確認できません」と表示し、現行メタデータで代用しません。実行者はAPIが返すidentityProvider/principalIdで表示し、表示名から権限を推測しません。

「改訂詳細を閉じる」で一覧へ戻ります。ブラウザが非表示の間は詳細を伏せ、復帰時に現在の認可で読み直します。別の改訂を選ぶと以前の詳細は非表示になります。別文書・別タブへの遷移や履歴読取り拒否時に古い詳細を表示しません。取得エラー時は表示された案内に従って再読取りしてください。改訂を読むだけでは既読状態を更新しません。

## 過去公開版の取下げ

1. 「版・改訂」で「過去版を含めて表示」を押し、履歴用途で取得したコンテンツ版一覧から対象の過去公開版を選びます。現在のreadHistory権限が必要です。100件を超えて次ページがある場合は「過去版をさらに表示」で続きから対象を探します。終端ではボタンがなくなります。通常表示のpublished用途は現行公開版、authoring用途は作業版を表示します。古い版が未取得なら「過去版をさらに表示」を押します。一覧の変更後は「過去版を最初から読み直す」で対象を確認し直します。
2. 「選択版を取下げ」を押し、文書名と対象の版番号を確認します。
3. 理由を入力して「取下げを確定」を押します。

現行でない公開版の取下げでは現行版は変わりません。原本・正式改訂・イベント履歴は保持されます。操作可否は対象版の現在のAPI認可結果に従います。指定版が一覧に見つからないときは、別の版へ自動的に操作対象を切り替えません。「過去版を最初から読み直す」で最新の一覧を取得し、対象を選び直してください。履歴用途の認可拒否時には正式改訂とその詳細も非表示にします。

履歴一覧の取得に失敗した場合は「再読み込み」で履歴用途の先頭を読み直します。選択版の詳細だけが失敗した場合は、その選択欄の「再読み込み」で同じ版の詳細を取得し直します。別版を選ぶと古い詳細の再試行案内は消えます。

通信結果が不明なときは「同じ内容で再試行」を使います。操作ID・対象版・期待revision・理由を固定して同じ操作の結果を確認します。競合や権限喪失で拒否された場合は「最新状態を確認」後、対象を確認してやり直します。未確認の操作は再読み込み前に解消してください。
