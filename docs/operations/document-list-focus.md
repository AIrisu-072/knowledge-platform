# 文書一覧のキーボード操作と遅延応答

一覧の初期表示と一覧内の選択では、選択した文書行へフォーカスします。登録ボタン、登録フォーム、ダイアログ、検索条件などを操作中に一覧の応答が遅れて到着しても、その操作先のフォーカスを保持します。登録ボタンは Enter で開き、キャンセルすると登録ボタンへ戻ります。

2026-10-09 の Ubuntu small 試験では登録ダイアログ表示が一件失敗しました。元の失敗にはキーイベントの記録がなく、原因との同一性は未確定です。別の制御試験で、遅れて到着した実一覧応答が登録ボタンから文書行へフォーカスを奪う不具合を確認し、この競合を修正しました。timeout の延長や Enter から click への置換はしていません。

実行結果は独立した検証記録を参照してください。この修正だけで small／大量文書資格の合格を示すものではありません。
