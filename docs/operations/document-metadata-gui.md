# 画面で文書共通属性を変更する

文書の「概要」から「メタデータを編集」を開きます。現在の権限と文書状態で操作できる場合にだけ保存できます。初回登録は[PR69](https://github.com/AIrisu-072/knowledge-platform/pull/69)の既存機能を使います。

## 変更できる項目

- 文書種別：`document_type`
- 所管部署：`owning_department`
- カテゴリ：`category`

変更理由を入力し、「保存する」で確定します。空文字や空白も値として保存できます。値を削除するときは対象項目の「削除」にチェックしてください。未設定の空欄を触らずに保存しても、新しい空文字の値は追加しません。

その他の属性、`extensions`、旧形式の `department` / `documentType` はそのまま残します。正本キーに文字列以外の値がある場合も、現値を表示し、明示して編集・削除した項目だけを変更します。タイトルや原本、Version固有の属性はこの操作では変更しません。

## 保存後

- 実際に値が変わったときだけ文書の競合検出番号が増えます。公開済みなら正式改訂のMinorも増えます
- 初回公開前には正式改訂を発行しません
- 「変更はありませんでした」はサーバーが無変更を確認した結果です。新しい正式改訂を作りません
- Version、原本、既読状態は変えません

## 競合・結果不明

別の編集、予約公開、権限失効で拒否された場合は、最新の状態を読み直して確認してください。フォームを開いた時点で操作可能でも、保存時には現在の権限を再確認します。

通信断などで保存結果が分からない場合は、入力を固定して「同じ内容で再送」を表示します。押すと同じ操作ID・同じ内容でサーバーに結果を確認し、別の新規変更としては送信しません。画面の値が一致するだけで、この操作の成功とは判断しません。

未確定の操作は、開いているアプリのメモリー内だけに保持します。フォームを閉じたり、別の文書へ移動して戻ったりしても同じ操作を確認できますが、ページ再読み込みやタブ終了後には再送用の情報が失われます。先に結果を確認してください。再読み込み後も結果が不明なら、新しい変更を繰り返す前に管理者へ確認してください。

公開終了後の文書は現在の通常詳細画面に表示されないため、この追加で終了文書まで編集できるとは扱いません。
