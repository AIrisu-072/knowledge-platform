# 文書GUIの登録・複数原本編集・公開予約取消・公開操作

この手順は、既存Document APIを画面から使うための追加機能を説明する。候補branchの検証手順であり、実サーバーへ導入済みとは限らない。導入する版は[手動導入手順](linux-manual-installation.md)と、その版の受入記録で確認する。本資料は導入先のcommit指定を変更しない。

## 文書を初めて登録する

1. 「文書」または「編集作業」の一覧で登録先フォルダーを選び、「文書を登録」を押す。全体表示ではルートへ登録する
2. 登録先を確認し、文書名と原本ファイル1件を指定する。1ファイル256 MiB以下にする
3. 「下書きとして登録」を押す。登録が確認できると「版・改訂」へ移動する
4. 登録直後はWORKINGの下書きで、正式改訂や公開版はまだ無い。公開する場合は対象と原本を確認し、既存の「公開する」で別途確定する

初回登録の通信結果が不明なときは、同じ文書を再登録しない。画面に「登録結果を確認」があればその照会を使い、なければ編集作業の一覧や管理者に結果を確認する。初回登録には重複を防ぐ操作IDが無いため、取下げ・公開終了と同じ再送はできない。

## 作業版の原本を差し替える

1. 「編集作業」で文書の「版・改訂」を開く。WORKINGがあるときは「作業版を編集」、現公開版だけのときは「新しい版を作成」を押す
2. 一覧の原本を確認し、変える原本の「差替ファイル」を選ぶ。複数原本を扱えるが、原本の追加・削除・並替・形式変更は今回含まない。論理位置と順番は保持する
3. 選択した原本に変換ファイルがある場合、新作業版へ引き継がない対象・件数を確認する。変えていない原本と変換物、旧公開版のファイルは保持する。自動再生成はしない。作業版だけにあった変換物は除外後の永久取得を保証しない
4. 「作業版を保存」または「新しい作業版を作成」を押す。保持する全ファイルを監査付きで取得してから、全manifestを送信する。途中の取得失敗や権限失効では保存しない
5. 保存しても公開中の版はそのまま。内容を確認して既存「公開する」で確定すると、新版へ一度に切り替わる。取下げを先に行う必要はない

初回未公開WORKINGも同じ版ID・番号のまま編集できる。未検査・検査不能だった初回原本の修復では旧原本の再検査を前提としないが、新原本の検査と既存mediaTypeの保持を必要とする。予約中は先に予約を取り消す。古い公開版を基準にした作業版は通常更新できない。現公開があるときは「現行版へ基準を更新」を押し、対象の現公開版を確認して「基準更新を確定」を使う。原本・補助ファイル・版番号を変えず、公開も行わない。公開版・取下げ済み版・公開終了した文書を直接変更しない。

再送に必要な原本・変換物は全て合算する。最大binary63件、各256MiB、JSON1MiB、headers等を含む全体1GiBと既存120秒の処理制限がある。共有FileIdや上限で全保持を保証できない場合は理由を表示して停止し、一部だけ保存しない。

結果不明は「同じ内容で再試行」で操作ID・対象・revision・全bytesを変えず回復する。別文書へ移動しても同じ起動中は未確認の要求を保持する。ブラウザーの再読込やタブ終了は避ける。確定拒否は「最新状態を確認」後、改めて保存する。公開切替後に古いpublished URLを使った新規取得が404になる場合は再読込する。historyへ勝手に切り替えない。

## 公開予約を取り消す

1. 「編集作業」から予約済みの文書を開き、「版・改訂」で対象WORKING版を選ぶ
2. 「公開予約を取り消す」を押し、文書・対象版・予定日時を確認する。予定日時にはAsia/TokyoとUTC offsetを表示する
3. やめる場合は「戻る」を押す。この時点では予約は取り消されない
4. 「予約を取り消す」を押し、「公開予約を取り消しました」を確認する。作業版と原本は保持される。改めて予約する場合は「予約公開する」から別の予約を行う

ボタンは現在の予約IDと現在capabilityが読み取れた場合だけ表示する。確認中に予約実行・再予約・権限変更があった場合は最新状態を確認する。取消結果が不明なら「同じ内容で再試行」を使う。以前の予約IDを維持して照合し、新しい予約を代わりに取り消さない。閉じた後は「未確認の取消を開く」から再開する。ページ再読込・タブ終了をまたぐ自動回復は保証しない。

## 現行の公開版を取下げる

1. 通常の「文書」一覧から公開中の文書を開き、「版・改訂」を選ぶ
2. 現行公開版を確認し、表示される「選択版を取下げ」を押す。表示がない場合は現在の権限・状態を確認する
3. 理由を入力し、対象と影響を確認する。取りやめるときは「キャンセル」を押す。この時点では送信されない
4. 「取下げを確定」を押し、結果を確認する

現行版の取下げ後は、サーバーが直前の公開版の安全性を確認できればその版へ復帰する。復帰できる版がなければ、現行の公開版は無くなる。画面はサーバーが返した結果を表示する。遠い過去版への自動復帰はしない。文書全体の公開を必ず終えたい場合は、次の「公開を終了」を使う。

今回の画面追加は通常公開画面からの現行版に限定する。「編集作業」はWORKINGの操作用で、過去の公開版を選んで取下げる画面は別途追加予定である。

## 文書全体の公開を終了する

1. 公開中の文書の「版・改訂」で「公開を終了」を押す
2. 文書全体が対象であることを確認し、理由を入力する
3. 次の影響を確認して「公開終了を確定」を押す
   - 通常の公開閲覧を終了し、その文書の公開予約を無効にする
   - 元の公開版・過去版・原本は保持する
   - 現行v0では通常の版作成・公開操作から再公開できない
4. 「文書の公開を終了しました」を確認する。公開終了後に詳細読取が「文書が見つからないか、閲覧できません」となるのは、通常の読取から外れた結果である

取下げと公開終了は異なる操作である。取下げ後には直前版へ復帰する場合があるが、公開終了は現行版を無くして通常公開を終了する。

## 結果不明・競合・権限失効

- 取下げ・公開終了で結果不明と表示されたら、「同じ内容で再試行」を使う。操作ID、対象、理由、期待するrevisionを変えずにサーバーへ照会・再送する
- 閉じたり、同じアプリ内で別文書へ移動しても未確認の操作は保持する。対象文書へ戻り「未確認の操作を開く」から続ける
- 未確認の操作がある間はブラウザーの再読み込みやタブ終了を避ける。操作要求はこのアプリ起動中のメモリだけに保持する。警告を無視して閉じた場合の自動回復は保証しない
- 競合や権限失効などの確定した拒否では「最新状態を確認」を押し、現在の対象・権限を確認してから新たに操作する。自動で新しい操作IDを作って再送しない
- すでに結果不明だった操作が、その後403などで拒否されても、最初の操作が未実行だったとは判断できない。同じ未確認操作を保持し、権限と操作履歴を管理者に確認する
- 照会IDが表示されたら問い合わせ時に伝える。文書内容や秘密情報を公開の問い合わせ先へ送らない

## 今回追加しない操作

過去版選択の取下げ、原本の追加・削除・並替、初回文書登録自体の複数原本化は別途扱う。予約取消の読取補修は既存予約IDの追加に限り、予約/取消の業務意味や新しい権限規則は変更しない。
