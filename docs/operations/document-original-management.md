# 原本の登録と作業版の構成変更

## 初回登録

文書一覧で登録先フォルダーを選び、「文書を登録」を押します。文書名を入力し、「原本ファイル」で複数ファイルを選択できます。複数選択した場合は一覧に全原本が表示されます。原本パスは文書内の相対パスです。重複、先頭の `/`、空の要素、`.`、`..`、バックスラッシュを含むパスは修正してください。

「上へ」「下へ」で順序を調整し、登録しない原本は「除外」で外します。最後の原本は除外できません。「下書きとして登録」は全原本を一つの文書の初版として登録します。一部だけを別の下書きとして残す登録は行いません。下書きを確認した後、公開は別の明示操作で行います。

登録結果を確認できない場合は、重複登録を避けるため再登録しないでください。「登録結果を確認」が表示されればその操作で全原本の登録結果を照合します。画面を閉じて開き直しても、結果不明の要求を再送しません。回復用識別子が取得できなかった場合や権限が失われた場合は、編集作業の一覧や管理者へ結果を確認してください。404や通信断だけで未登録とは判断できません。

## 作業版の編集

文書の「版」から作業版を選び、「作業版を編集」を押します。公開版・過去版をこの画面から直接書き換えることはありません。公開版から新しい作業版を作る導線では原本構成を変更せず、作成後の作業版で変更します。

- 原本を差し替える場合は対象原本の「差替ファイル」で同じ形式のファイルを選びます。その原本に属する古い補助ファイルは新しい作業版から除外されます。
- 原本を追加する場合は「原本を追加」を押し、新規ファイルと文書内の相対パスを指定して「追加原本を確定」を押します。追加原本には補助ファイルを自動生成しません。
- 原本を「除外」すると、その原本と補助ファイルが保存候補から外れます。保存前なら除外した原本名の「除外を取消」で戻せます。最後の原本は除外できません。
- 「上へ」「下へ」で表示順を変更します。構成を変更した保存では、表示順で順序番号を0から振り直します。構成を変えない差替え保存は元の順序番号を維持します。既存原本のパスは変更できません。

候補の原本・補助ファイルを確認し、「作業版を保存」を押します。保持する原本と補助ファイルも、現在の権限で取得して保存します。取得に失敗したときは保存を送信しません。編集や保存だけで現行公開版を切り替えません。公開を確定すると既存の公開処理が新しい版へ切り替えます。旧公開版の履歴は保持します。

競合・権限失効などで保存が拒否された場合は「最新状態を確認」してから編集をやり直します。保存結果が不明の場合は「同じ内容で再試行」で同じ操作IDと全ファイルを再送します。別の編集要求へ差し替えません。結果を確認するまで再読み込みやタブを閉じることを避けてください。

## 上限と運用上の境界

原本・補助ファイルを合算して最大63件、各256 MiB、manifest JSON 1 MiB、JSON・境界を含む全送信1 GiB、処理120秒です。保持ファイルに共有File IDがある場合は安全な全量再送ができず停止します。容量や通信時間により上限未満でも保存が失敗する場合があります。

作業版から外したファイルを永久に取得できる保証はありません。公開履歴の取得には既存の履歴権限が必要です。文書詳細の正常表示による既読の意味は変えません。原本の閲覧完了を証明する機能ではありません。

実配備では、この機能のexact-head検証が完了したコミットを採用し、既存の導入・backup/restore手順に従ってください。本書は対象PCへの導入、実アカウントの設定、本番認証・TLSの実施証拠ではありません。
